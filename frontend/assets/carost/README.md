# Generated concept photography

The optional media pack is named carost-generated-vehicle-assets.zip. Extract its contents at the root of the repository so the following paths exist:

- frontend/assets/carost/hero.webp
- frontend/assets/carost/sedan-sunset.webp
- frontend/assets/carost/electric-crossover.webp
- frontend/assets/carost/sedan-coast.webp
- frontend/assets/carost/suv-mountain.webp
- frontend/assets/carost/interior-passenger.webp
- frontend/assets/carost/interior-driver.webp

The website renders custom vector car artwork automatically when a photo file is absent. The AI-generated exterior photos are **mood imagery**, not guaranteed to depict the precise trim, brand, year, or vehicle named in any fictional demo listing. Never present them as actual inventory photos.
